# Auston Balwinski

Applied data scientist working on deep learning for time series, causal inference, and large-scale health data. M.S. Applied Data Science, University of Michigan (2026).

## Selected projects

| Project | What it does | Techniques |
|---|---|---|
| **[Blood-Glucose Forecasting (CRNN)](https://github.com/Auston-B/blood-glucose-crnn)** | Predicts blood glucose 5–60 minutes ahead from continuous glucose monitor data. Per-patient transfer learning roughly halves 30-minute forecast error versus a single population model. | PyTorch, Conv1D + LSTM, transfer learning, time-series preprocessing |
| **[Ocean Health Monitoring](https://github.com/Auston-B/Ocean-Health-Monitoring)** | Predicts dissolved oxygen across 600k NOAA World Ocean Database records (R² = 0.98) and clusters global measurements into water-mass regimes. I owned the unsupervised pipeline end to end. | Clustering (KMeans, HDBSCAN, Agglomerative), PCA/t-SNE, random forests, ablation and failure analysis |
| **[Michigan Automatic Voter Registration](https://github.com/Auston-B/avr-analysis)** | Difference-in-differences study of whether Michigan's AVR law raised youth registration and turnout, using CPS microdata. Reports fragile, directionally mixed results rather than overstating them. | Causal inference, two-way fixed effects, event study, clustered SEs |
| **[Teaching GPT-2 to Answer Questions](https://github.com/Auston-B/gpt2-squad-qa)** | Compares three ways of adapting `gpt2-medium` to SQuAD — prompting, QA fine-tuning, and instruction tuning — evaluated zero-shot and few-shot on token-F1. | Transformers, fine-tuning, instruction tuning, LLM evaluation |

More in [my repositories](https://github.com/Auston-B?tab=repositories), including diffusion models from scratch, sleep-health prediction and fairness analysis across 59,757 *All of Us* participants, and geospatial election visualization.
